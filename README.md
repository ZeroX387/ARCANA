# ARCANA

**ARCANA** — 2D Magic Survival / Bullet Heaven с глубокой системой магии, развития персонажей и экспериментальных слияний заклинаний.

Проект разрабатывается на **Godot 4 + GDScript**. Первая целевая платформа — Android; архитектура должна сохранять возможность сборки для ПК.

## Статус
Проект находится на ранней стадии. Текущая цель — Demo 0.1: настоящий играбельный прототип с перемещением, врагами, автоматическими заклинаниями, опытом, улучшениями и первыми слияниями.

## Структура
- `docs/` — GDD, правила и документация.
- `game/` — проект Godot.
- `tests/` — тесты и проверки.

## Запуск
1. Установите Godot 4.x.
2. Откройте в Godot папку `game/` (файл `project.godot`).
3. Запустите главный проект.

## Основные принципы
- Это одиночный survival-roguelike, не MMORPG.
- Мана во время забега — валюта магазина. Заклинания не расходуют её при применении.
- Сложность должна создавать интересные боевые ситуации, а не сводиться к бесконечному росту здоровья врагов.
- Сначала создаём рабочую игру, затем расширяем системы небольшими проверяемыми шагами.

## Участие
